# УЗД-Дайджест — Telegram-бот

Бот стежить за новими статтями в PubMed за темами ультразвукової діагностики,
генерує коротку анотацію українською через Claude API, оцінює рівень доказовості
(High/Medium/Low) і публікує дайджест у Telegram-канал. Також працює як
інтерактивний бот — можна запитати статті за темою або пошуковим словом.

**Джерело даних:** офіційні анотації (abstract) статей з PubMed — безкоштовна база
NCBI. Повні тексти статей ніде не завантажуються й не копіюються — лише
перефразована власними словами коротка анотація + посилання на оригінал.

**Теми, які вже налаштовані** (config/topics.py): судини шиї і голови, м'які
тканини, слинні залози, щитоподібна залоза (біопсії, РЧА), молочні залози й
лімфовузли (біопсії), черевна порожнина та нирки, гострі й онкологічні
захворювання, урологія, гінекологія, репродуктологія, а також окрема тема —
нові рекомендації/протоколи асоціацій (EFSUMB/AIUM/ESR/ACR).

**Шкала доказовості** — проста власна шкала, не формальна GRADE:
- 🟢 **High** — систематичні огляди, мета-аналізи, РКД, офіційні рекомендації асоціацій
- 🟡 **Medium** — проспективні когортні дослідження, великі ретроспективні серії
- 🔴 **Low** — описи випадків, малі ретроспективні вибірки, пілотні дослідження, думка експертів

## Крок 1. Створити Telegram-бота

1. У Telegram знайдіть **@BotFather** → команда `/newbot`.
2. Дайте боту ім'я та унікальний username (має закінчуватись на `bot`).
3. BotFather видасть **токен** виду `123456789:AAExample...` — збережіть його.

## Крок 2. Створити канал і додати бота

1. Створіть Telegram-канал (публічний або приватний).
2. Додайте вашого бота в канал як **адміністратора** (з правом публікації повідомлень).
3. **ID каналу**:
   - для публічного каналу — це `@username_каналу`;
   - для приватного — потрібен числовий ID (можна отримати, переславши будь-яке
     повідомлення з каналу боту **@userinfobot**, або тимчасово зробивши канал
     публічним, скопіювати `@username`, потім повернути приватність).

## Крок 3. Отримати ключ Anthropic API

1. Зареєструйтесь на https://console.anthropic.com
2. Settings → API Keys → Create Key. Поповніть баланс (для початку достатньо
   кількох доларів — див. орієнтовну вартість нижче).

## Крок 4. (Бажано) Отримати NCBI API-ключ

Без нього теж працює, але з ключем вищі ліміти запитів до PubMed.
https://www.ncbi.nlm.nih.gov/account/settings/ → API Key Management.

## Крок 5. Розгортання — Oracle Cloud (безкоштовно назавжди)

Бот має працювати безперервно, тож потрібен постійно ввімкнений сервер.
Обраний варіант — **Oracle Cloud Always Free**: справжня безкоштовна віртуальна
машина (VM), без обмеження в часі. Єдина ваша поточна витрата — Anthropic API
(орієнтовно $1-2/міс, див. розділ "Орієнтовна вартість").

Знадобиться терміналом (командний рядок) — усі команди нижче можна просто
скопіювати й вставити, пояснення є до кожної.

### 5.1. Реєстрація на Oracle Cloud

1. Перейдіть на https://www.oracle.com/cloud/free/ → "Start for free".
2. Заповніть особисті дані, підтвердіть телефон по SMS.
3. Введіть дані банківської картки — це лише для верифікації особи,
   **гроші не списують**, поки ви самі не перейдете на платний тариф.
4. Оберіть **Home Region** — краще щось із ЄС (наприклад, Germany Central
   (Frankfurt) або аналогічний регіон, ближчий до України).

### 5.2. Створення віртуальної машини

1. У консолі Oracle Cloud: ☰ меню → **Compute → Instances → Create Instance**.
2. Name: `usd-bot`.
3. У блоці "Image and shape" натисніть **Edit**:
   - Image: залиште **Canonical Ubuntu** (остання LTS-версія, напр. 24.04).
   - Shape: натисніть "Change shape" → **Virtual Machine** → **Specialty and
     previous generation** → оберіть **VM.Standard.E2.1.Micro**.
     Це найслабша, зате **гарантовано доступна** безкоштовна конфігурація —
     для нашого легкого бота цього вистачає з запасом. (Потужніший
     Ampere A1 теж безкоштовний, але часто видає помилку "out of capacity" —
     можна спробувати пізніше, коли освоїтесь.)
4. У блоці "Networking" залиште все за замовчуванням — важливо, щоб була
   галочка **"Assign a public IPv4 address"**.
5. У блоці "Add SSH keys" оберіть **"Generate a key pair for me"** і натисніть
   **"Save private key"** — файл (наприклад `ssh-key-....key`) збережеться на
   ваш комп'ютер. Це єдиний спосіб зайти на сервер — зберігайте надійно.
6. Натисніть **Create** і зачекайте 1-2 хвилини, поки стан не стане "Running".
7. На сторінці інстансу скопіюйте **Public IP Address** — знадобиться далі.

### 5.3. Підключення до сервера (SSH)

**Windows 10/11:** відкрийте "Термінал" (Windows Terminal) або PowerShell,
перейдіть у папку із завантаженим ключем і виконайте:
```
cd Downloads
ssh -i ssh-key-....key ubuntu@ВАШ_PUBLIC_IP
```

**macOS/Linux:** відкрийте Термінал і виконайте:
```
chmod 400 ~/Downloads/ssh-key-....key
ssh -i ~/Downloads/ssh-key-....key ubuntu@ВАШ_PUBLIC_IP
```

На запитання про fingerprint надрукуйте `yes`. Якщо все ок — побачите
запрошення виду `ubuntu@usd-bot:~$`. Ви зайшли на сервер.

### 5.4. Встановлення потрібних програм на сервері

Виконайте по черзі (це вже команди НА сервері, після підключення по SSH):
```
sudo apt update && sudo apt upgrade -y
sudo apt install -y python3 python3-pip python3-venv git unzip
```

### 5.5. Завантаження коду бота на сервер

Найпростіше — через GitHub. Спершу на своєму комп'ютері створіть репозиторій
на github.com і завантажте туди файли з `usd-bot.zip` (через "Add file →
Upload files" у браузері). Потім на сервері:
```
git clone https://github.com/ВАШ_USERNAME/ВАШ_РЕПОЗИТОРІЙ.git
cd ВАШ_РЕПОЗИТОРІЙ
```

### 5.6. Налаштування середовища

```
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
nano .env
```
У редакторі `nano` впишіть свої значення (токен бота, ID каналу, ключ
Anthropic тощо). Збережіть: `Ctrl+O`, потім `Enter`, вийдіть: `Ctrl+X`.

### 5.7. Тестовий запуск

```
python3 main.py
```
Маєте побачити `Бот запущено...`. Перевірте в Telegram командою `/start`.
Якщо відповідає — все працює. Зупиніть тест: `Ctrl+C`.

### 5.8. Автозапуск 24/7 (systemd)

Щоб бот працював постійно й сам перезапускався після збоїв чи перезавантаження
сервера, створіть службу:
```
sudo nano /etc/systemd/system/usd-bot.service
```
Вставте (замініть шлях, якщо назва папки інша):
```
[Unit]
Description=UZD Digest Telegram Bot
After=network.target

[Service]
Type=simple
User=ubuntu
WorkingDirectory=/home/ubuntu/ВАШ_РЕПОЗИТОРІЙ
ExecStart=/home/ubuntu/ВАШ_РЕПОЗИТОРІЙ/venv/bin/python3 /home/ubuntu/ВАШ_РЕПОЗИТОРІЙ/main.py
Restart=always
RestartSec=10

[Install]
WantedBy=multi-user.target
```
Збережіть (`Ctrl+O`, `Enter`, `Ctrl+X`), тоді:
```
sudo systemctl daemon-reload
sudo systemctl enable usd-bot
sudo systemctl start usd-bot
sudo systemctl status usd-bot
```
У статусі має бути `active (running)`.

### 5.9. Перегляд логів і оновлення коду

```
journalctl -u usd-bot -f          # логи в реальному часі, Ctrl+C щоб вийти
```
Коли захочете оновити код (наприклад, додати нову тему):
```
cd ~/ВАШ_РЕПОЗИТОРІЙ
git pull
sudo systemctl restart usd-bot
```

### 5.10. Захист від несподіваних витрат

У консолі Oracle Cloud: **Billing & Cost Management → Budgets → Create
Budget** — виставте бюджет $1 і сповіщення на email. Якщо колись випадково
щось платне підключиться — одразу дізнаєтесь.

> **Альтернатива, якщо Oracle Cloud здасться складним:** Railway.app —
> простіше в налаштуванні (деплой у 3 кліки з GitHub), але коштує від
> $5/міс. Кроки: реєстрація на railway.app → New Project → Deploy from
> GitHub repo → додати змінні з `.env.example` у розділі Variables → Start
> Command `python main.py`.

## Як це працює

1. Кожні `CHECK_INTERVAL_HOURS` годин бот перевіряє PubMed за запитами з
   `config/topics.py` (за замовчуванням шукає статті за останні
   `LOOKBACK_DAYS` днів).
2. Нові статті (яких ще немає в базі `usd_bot.db`) відправляються в Claude API
   для генерації короткої анотації українською + оцінки рівня доказовості.
3. Результат зберігається в базу і публікується в канал.
4. У приватному чаті з ботом доступні команди:
   - `/теми` — список тем
   - `/тема thyroid` — останні статті за темою
   - `/пошук РЧА` — пошук за ключовим словом у назвах/анотаціях
   - `/останні` — останні опрацьовані статті за всіма темами

## Як додати або змінити тему

Відредагуйте словник `TOPICS` у `config/topics.py` — додайте новий ключ,
українську назву (`label`) і пошуковий запит PubMed (`query`, англійською,
у синтаксисі PubMed: `[Title/Abstract]`, `AND`/`OR`, лапки для фраз).

## Орієнтовна вартість

При обраній схемі (Claude API + Oracle Cloud):

- **Хостинг (Oracle Cloud Always Free)**: **$0/міс назавжди** — потрібна лише
  картка для одноразової верифікації особи при реєстрації, списань немає.
- **PubMed**: **$0** — безкоштовно, без обмежень для такого обсягу запитів.
- **Anthropic API (Claude Sonnet 5)**: ≈$0.004-0.005 за одну анотацію
  (система+анотація статті на вході ≈1000 токенів, коротке резюме+оцінка
  доказовості на виході ≈250 токенів; тарифи $2/$10 за мільйон токенів
  вхід/вихід). При реалістичному потоці ~50-200 нових статей на місяць по
  всіх 11 темах — це **≈$0.25-1/міс**. Навіть при аномально високому потоці
  (500+ статей/міс) — це $2-2.5. Актуальні тарифи завжди на
  https://claude.com/pricing, оскільки можуть змінюватись.

**Разом: орієнтовно $1-2/міс**, і майже вся ця сума — не хостинг, а сам AI.
Якщо захочете звести AI-витрати ще ближче до нуля — можна перейти на
безкоштовний рівень Google Gemini API (Flash-моделі), пожертвувавши трохи
якістю анотацій; дайте знати, якщо цікаво — можу переробити `summarizer.py`
під це.

## Обмеження та важливі нотатки

- Бот працює лише з **англомовною** базою PubMed (це стандарт для медичної
  літератури) — анотації генеруються українською, самі джерела — англійською.
- Оцінка рівня доказовості — **автоматична попередня орієнтація**, а не заміна
  критичного аналізу першоджерела лікарем.
- Якщо потрібно додати інші джерела (напр. RSS конкретних журналів, сайти
  асоціацій без PubMed-індексації) — це окремий модуль на кшталт `fetcher.py`,
  дайте знати, і можна розширити.
